# Semantic HTML and Accessibility: What I Learned and Fixed

## Introduction

During Week 1 of the IYF Weekend Academy Season 12 course, I learned that building a website is not only about making it look attractive. A good website should also have a clear structure and be accessible to different users.

Semantic HTML helps browsers, search engines, and assistive technologies understand the purpose of different parts of a webpage.

## What I Learned

Semantic HTML uses meaningful elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` instead of relying on generic containers for everything.

For example, using a `<nav>` element to group navigation links makes the purpose of that section clearer than using a plain `<div>`.

I also learned that accessibility includes providing labels for form fields, using appropriate heading levels, and ensuring that links and buttons can be operated using a keyboard.

## What I Improved

In my portfolio, I used semantic elements to organize the navigation, main content, project sections, contact form, and footer.

I added labels to the contact form so users can identify each field. I also included visible keyboard focus styles to make interactive elements easier to navigate.

These improvements make the website easier to understand and use.

## Conclusion

Semantic HTML and accessibility are important parts of web development. They help create websites that are more organized, usable, and inclusive.

As I continue learning, I will apply these principles to my future projects.
