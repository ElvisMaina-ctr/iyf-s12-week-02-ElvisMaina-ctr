# Week 2 — Responsive Portfolio Website

A personal portfolio website created as part of the IYF Weekend Academy Season 12 web development course. The project builds on my Week 1 HTML work by applying CSS fundamentals, Flexbox, CSS Grid, and responsive design to create a website that adapts to different screen sizes.

## About the Project

This portfolio introduces me as a web development learner and provides a place to showcase my skills and projects. It includes a navigation menu, an introduction section, project cards, and a contact form layout.

The project focuses on creating a clear, accessible, and responsive user experience using HTML and CSS.

## Features

- Responsive navigation menu
- Introduction or hero section
- Project cards displayed using CSS Grid
- Flexbox layouts for aligning content
- Reusable colors, spacing, and typography styles
- Button and project-card hover effects
- Styled contact form
- Responsive layouts for mobile, tablet, and desktop screens
- Semantic HTML structure to support accessibility and maintainability

## Technologies Used

- **HTML5** — page structure and semantic content
- **CSS3** — styling and layout
  - Flexbox
  - CSS Grid
  - Media queries
  - CSS custom properties
  - Hover and focus states
