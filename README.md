# Week 2: CSS Mastery

## Project Overview

This project is a responsive personal portfolio website
created for Week 2 of the IYF Weekend Academy Season 12
web development course.

It builds on the Week 1 portfolio and demonstrates
CSS fundamentals, the box model, Flexbox, Grid,
and responsive design.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Features

- Responsive navigation
- Hero section
- About section and skills
- Project cards
- Contact form
- Multi-column footer
- Button and card hover effects
- Mobile-friendly layouts

## Week 2 Daily Challenges

1. Style a button with hover states.
2. Create a card component.
3. Build a hero section.
4. Style a form.
5. Create a footer with multiple columns.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## GitHub Pages

1. Open the repository on GitHub.
2. Select Settings, then Pages.
3. Select the `main` branch and root folder.
4. Save and wait for deployment.
